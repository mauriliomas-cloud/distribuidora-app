Bem-vindo ao DistribControl! 🎉
Vamos configurar seu sistema em 4 passos simples. Você vai precisar de uma conta Google — é grátis e você provavelmente já tem uma.
O que você vai precisar:
✓ Uma conta Google (Gmail)
✓ 5 minutos para criar seu banco de dados
✓ Copiar e colar 2 informações no app

Por que isso?
Seus dados ficam na sua própria conta do Google — você tem controle total, é grátis e não depende de ninguém.
Passo 1 — Crie seu banco de dados
Vamos criar um projeto no Firebase, que é o serviço gratuito do Google para guardar seus dados na nuvem.
1. Clique no botão abaixo para abrir o Firebase
2. Clique em "Criar um projeto"
3. Digite um nome: distribuidora-minha
4. Desative o Google Analytics (não precisa)
5. Clique em "Criar projeto"
6. Aguarde e clique em "Continuar"
🔥 Abrir Firebase Console
Depois de criar o projeto:
No menu lateral clique em Firestore Database → Criar banco de dados → Modo produção → Escolha a região southamerica-east1 (São Paulo) → Ativar
Passo 2 — Cole suas credenciais
Agora vamos conectar o app ao seu Firebase. Siga os passos para copiar as credenciais:
1. No Firebase Console, clique no ícone </> (Web)
2. Digite um apelido: distribuidora-app
3. Clique em "Registrar app"
4. Copie o objeto firebaseConfig que aparecer
5. Cole cada campo abaixo
Passo 3 — Crie o usuário administrador
Crie o primeiro acesso do sistema. Este usuário terá permissão total.
Guarde bem essa senha! Ela é salva de forma segura no seu banco de dados. Você poderá criar outros usuários depois de entrar no sistema.
